## Defaults to disclose at the checkpoint 4 report (step 3)

- A cell holds one paragraph: Enter moves down a row, and Enter in the last row ends editing. Tab after the last cell adds a row.
- A corner drag scales a table's type with it, as with text boxes.
- PowerPoint cannot turn a table, so a turned table goes to PowerPoint as a picture.
- In PowerPoint, cell text stays fully opaque when the table is see-through.
- An old deck's table gains an outer frame line. A new table's grid colour is the theme's muted colour.
- PowerPoint import: a table takes one look per kind of row (header, body, banded) from a sample cell; looks set on single cells or on the first or last column are not kept. Merged cells come in split, with the text in the first cell.
